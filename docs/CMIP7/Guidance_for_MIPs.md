# CMIP7 Participation Guidance for MIPs

!!! tip "Documentation in progress"

    This section is in development and will be updated


The [WCRP CMIP7 webpage](https://wcrp-cmip.org/cmip-phases/cmip7/) provides an overview of CMIP7, including community MIPs (Model Intercomparison Projects) and a [MIP registration form](https://wcrp-cmip.org/mips/#mip_registration).

General guidance on setting up a MIP is provided in [Appendix B of Dunne et al. (2025)](https://gmd.copernicus.org/articles/18/6671/2025/#section7).

Guidance on naming MIP experiments is [available here](https://zenodo.org/records/14929769).

## 1. Registration with the CMIP IPO
The first step for any MIP is registering with the CMIP IPO. [You can register here](https://wcrp-cmip.org/mips/#mip_registration). Once registration has been verified by the IPO, you will see your MIP appear in the [Registered MIPs gallery](https://wcrp-cmip.org/mips/#registered_mips). 

During registration, we ask for MIP scientific and technical contact details - these are important as we will use these for MIP communications, especially during the experiment registration process (see below).

## 2. Activity and Experiment registration

Information on registering new activities (MIPs) and experiments in the Controlled Vocabularies can be found within the CV registration documentation [here (for activity registration)](cv_registration.md#23-activity-registration) and [here (for experiment registration)](cv_registration.md#24-experiment-registration). 

!!! warning "Please note" 

    MIP registration with the IPO and activity registration in the CVs are two distinct steps. All three steps (MIP registration with IPO, activity registration in the CVs, and experiment registration in the CVs) are required before experiments will be accepted into the CVs.

## 3. Creating a data request
The Data Request for CMIP7 was devided into two phases: the Harmonised request and the Unharmonised request. The Harmonised request was developed through a large public consultation exercise and was intended to include data requested on the IPCC AR7 timeline. The Unharmonised request is intended to capture additional CMIP7 requests on MIPs' own timelines.

The Harmonised request has now been finalised (subject to minor updates when errors are found). You can find the latest version of the [Harmonised request here](https://wcrp-cmip.org/cmip7-data-request-latest).

The process for requesting additional variables from experiments not included in the Harmonised request is currently being finalised. We expect to release more information for MIPs on this in October/November 2026.
